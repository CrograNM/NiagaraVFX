--------------------------------------------------------
<Spawn And Update>

Spawn = Begin Play
Update = Event Tick

- Emitter Spawn : 가끔만 사용
- Emitter Update : 스폰할 파티클 갯수 등 설정
- Particle Spawn : Initial Size / Location / Color / Life time 등등
- Particle Update : 파티클 움직임 제어 (Movement / Scaling / Fading 등)

--------------------------------------------------------
<Material>

Blend Mode - Additive / Translucent 가 많이 사용됨.
- Additive : 검은색이 투명하게 렌더링 됨.
- Translucent : 색이 어두워지는걸 표현 가능.

Shading Model
- Default Lit : 그림자나 빛을 모두 드리울 수 있음.
- Unlit : 그림자나 빛이 드리워지지 않음 -> VFX에 적합

--------------------------------------------------------
<화염방사기 복습>

- Renderers
스프라이트 렌더러만 사용했음 (-> 머티리얼 및 Sub Image Size 변경)
Module: 	[Shape Location, Add Velocity], 
		[Scale Sprite Size, Solve Force, SubUVAnimation, Color or Scale Color]

- Elements
불꽃과 연기를 만드는 일부 텍스쳐와 노멀 맵만 사용했음

- Forces/Material
열 디스토션
노드: 		[Panner 노드로 속도 삽입, Normal Texture, 일렁이는 텍스쳐]
머티리얼:	[Index Of Refraction, Translucent, Unlit, Opacity 0]

불꽃
Static Switch Params 활용하여 기존의 SingleTexture_Additive 머티리얼을 재사용함.
Sine_Remapped를 사용해 시간에 따라 밝기가 왔다갔다 하는 로직의 노드를 구성함.
